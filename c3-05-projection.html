Projection

We assume others think, feel and want what we do.

How it works

Our own mind is the only one we can see from inside, so it becomes the default model for everyone else.

Example

"I would be bored, so the teenagers will be bored too."

Ross, L., Greene, D. & House, P. (1977). The false consensus effect.
